# Absensi Safety Briefing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menu Absensi di HP (ADMIN_ES + ADMIN): dua pengabsen mengisi staf berbeda, simpan jalan di latar belakang lewat antrean, rekap bulanan dan teks WhatsApp dibuat server.

**Architecture:** Backend Apps Script: kolom `db_Petugas.tim_yandal` diganti `tim` (semua tim), modul baru `backend/src/modules/66_Absensi.js` (tab `abs_Absensi` di spreadsheet baru `ABSENSI_SHEET_ID`, aksi `getAbsensi` / `simpanAbsensi`). HP Flutter: `features/absensi/` dengan antrean lokal bergaya `AntreanTemuanAdmin`, dikirim oleh `SyncController`.

**Tech Stack:** Google Apps Script (Node `node:test` + `tests/harness.js` untuk uji), Flutter/Dart (`flutter test`).

**Spec:** `docs/superpowers/specs/2026-11-01-absensi-design.md`

## Global Constraints

- 7 status, simbol dan nama persis: `HADIR` ✅ Hadir Tepat Waktu, `TELAT` *️⃣ Hadir Telat, `TANPA_KET` ❌ Tidak Hadir Tanpa Keterangan, `KET` 📌 Tidak Hadir dengan Keterangan, `TMK` 🇨🇭 TMK sakit dengan SKS, `CUTI` 🆓 Cuti kerja, `IZIN` 🔤 Izin tidak masuk kerja. `keterangan` wajib untuk `KET` dan `IZIN`, ditolak untuk status lain.
- Satu baris per `tanggal + petugas_id`. Tanggal = hari berjalan WIB; server menolak tanggal lain (`HARI_LAMPAU` / `HARI_DEPAN`), oleh siapa pun.
- Baris yang `diabsen_oleh`-nya akun lain **tidak bisa diubah** (`DIKUNCI_PENGABSEN_LAIN`); akun yang sama boleh mengubah kapan pun hari itu. Dicek di dalam `denganLock_`.
- Peserta = `db_Petugas` aktif dengan `tim` terisi dan tim itu aktif di `db_Tim`. Staf Yandal (tim `jenis == 'YANDAL'`) yang belum diabsen tidak ditulis di teks WhatsApp; staf lain yang belum diabsen ditulis `⏳ belum diabsen`.
- Teks WhatsApp: angka rekap selalu ditulis (`❌1`), rekap = hitungan bulan berjalan sampai hari ini **termasuk hari ini**, ✅ hanya penanda hari ini (tidak dihitung, tanpa angka), jam "Pukul" = waktu simpan terakhir hari itu (WIB, `HH.mm`), alasan hari ini di belakang baris.
- Urutan simbol di teks: 🇨🇭 🆓 🔤 📌 *️⃣ ❌, lalu ✅ atau ⏳, lalu alasan. Urutan tim = urutan baris `db_Tim`; urutan staf = nama A-Z.
- Mengikuti pola kode yang ada: SisiError_ untuk galat, `validasi_` allowlist, `denganLock_`, `auditLog_`, `amanSheet_` untuk teks bebas, ID spreadsheet lewat `cfg_()` + `CFG_JSON`.
- Versi backend (`VERSI_BACKEND_` di `09_Versi.js`) sama dengan `version:` di `mobile/pubspec.yaml` (dicek tes): `1.0.51` / `1.0.51+222`.

## Review Focus

- Antrean berisi item hari kemarin dikirim hari ini: server menolak `HARI_LAMPAU`, HP menandai galat dan tidak mengulang tanpa henti.
- Dua HP menyimpan staf yang sama hampir bersamaan: tepat satu menang, yang lain `DIKUNCI_PENGABSEN_LAIN`, tidak ada baris ganda.
- Kirim ulang item yang sama (sinyal putus setelah server menerima): hasil sama, bukan galat dan bukan baris ganda.
- Hari pertama bulan: rekap mulai dari nol; hari terakhir bulan tidak bocor ke bulan berikutnya.
- Petugas pindah tim / dinonaktifkan sesudah diabsen: baris riwayat tetap, rekap bulan tetap terhitung, daftar layar hanya peserta aktif.
- Ganti akun di HP yang sama: antrean akun lama tidak terkirim dengan akun baru.
- `keterangan` berawalan `=` atau `@` tidak menjadi formula di sheet.
